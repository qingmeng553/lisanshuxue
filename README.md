## 后端环境

  该项目使用django架构，后端所需包我都已经写入requirement.txt,所以在配置环境时，请在descrete路径中打开终端，输入以下指令

```bash
python -m venv venv
source venv/Scripts/activate  # Linux 用 venv\bin\activate
pip install -r requirements.txt
```

## 前端环境

**无node.js.环境需自行配置，配置完成后进行以下步骤**

  实不相瞒，前端套用了颇多免费的和ai造的vue组件模板。配置环境时，在frontend路径中打开终端，输入以下指令

``` bash
npm install
```

## 启动

  在descrete路径打开终端，输入

``` bash
python manage.py runserver
```

 同样地，在frontend路径终端输入

``` bash
npm i element-plus
npm run dev
```

  最后，在任意浏览器（推荐谷歌），进入ip

http://localhost:5173/

即可
